Process

How I Work

Five steps, from the first conversation to a site or application you can use.

  1. 01

    Discover

    We talk through the business, who will use it, and what has to be live.

  2. 02

    Plan

    I set the pages or features, the tools, and the scope before building.

  3. 03

    Build

    I build the site or application so it works on the screens your customers use.

  4. 04

    Review

    You see the work, send feedback, and I adjust it before it goes live.

  5. 05

    Launch

    I put it live and hand over what you need to run it, including fixes we have agreed.

FAQ

Questions clients usually ask

A short brief is enough to start. These are the questions that usually come up first.

01How do we start a project?

Send a short note about what you want to build, any current website, and your timeline. Use the enquiry form, email or WhatsApp. I'll review it and reply with the next steps.

02Do you work with existing websites?

Yes. I can fix, improve or extend a website or application that already exists, including layout issues, new sections and integrations.

03Can you build a website from a Figma design?

Yes. If you already have a design, I can build from it. If you don't, we can define the pages and structure before development starts.

04Can you customize Shopify themes?

Yes. I work on theme customization, custom Liquid sections, product pages and other storefront improvements.

05Can you build a custom admin panel?

Yes. I build admin interfaces with authentication, role-based access and workflows connected to an API and database.

06Can you work with an existing backend or API?

Yes. I can build a frontend against an API you already have, or extend the backend when the project needs it.

07Do you provide post-launch maintenance?

Yes, when we agree the scope. That can include fixes, content or section updates, and deployment support.

08How is project pricing determined?

Pricing depends on scope, features, integrations and timeline. Share what you need and I'll discuss a suitable approach. There is no single fixed price listed here.
