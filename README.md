# My-portfolio

Freelance site for Gaurav Kuntal: business websites, Shopify stores, and custom web applications.

## Setup

Clone the repo and open it with a local server. No build step.

```bash
git clone https://github.com/kuntalgaurav2001/My-portfolio.git
cd My-portfolio
python3 -m http.server
```

Then open `http://127.0.0.1:8000/`.
